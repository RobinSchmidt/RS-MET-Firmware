FM-1 Resources

The Firmware Hub
https://thefirmwarehub.com/
-Website with firmwares for the FM-1
 https://thefirmwarehub.com/kb/               Instructions for publishing a firmware
 https://thefirmwarehub.com/tools/rescue/     How to recover from bricked
 https://thefirmwarehub.com/tools/            Dev Tools such as emulators etc.

https://github.com/m-vave/fm1_open
-The landing page for getting started with custom firmware development for the FM-1.

https://open.m-vave.com/fm1-workbench
-A web-based emulation of the device that runs in the browser
-Q: Can it be used to test custom firmware?

FM-1 emulator
https://github.com/joakimeriksson/fm1-emu
-FM-1 (and SMK-37) emulator to runs firmwares in the browser and natively
 https://joakimeriksson.github.io/fm1-emu/?fw=felucca&mhz=100  Run it online
 

https://github.com/sbegueria/fm1-dev-wiki
-Lots of .md files with relevant content. Especially important seem to be these:
 https://github.com/sbegueria/fm1-dev-wiki/blob/master/docs/Hardware-Overview.md
 https://github.com/sbegueria/fm1-dev-wiki/blob/master/docs/Known-Projects.md
 https://github.com/sbegueria/fm1-dev-wiki/blob/master/docs/AI-Skills.md

M-VAVE FM1 Resource Hub
https://github.com/aroum/fm1-custom-fw
-Custom Firmwares & MIDI SysEx Protocol Documentation
-Curated directory and reference hub for the M-VAVE FM1 synthesizer gathering community custom
 firmwares, documentation, tools, MIDI SysEx protocol details

Felucca
https://github.com/hugelton
https://github.com/hugelton/Felucca
-Felucca is a popular firmware that features virtual analog synthesis. (verify!)
-Hugelton's other repos may also be of interest -> figure out what else is there.
 https://github.com/hugelton/Felucca-Engines   The DSP engines
 https://github.com/hugelton/felucca-bsp       The plumbing layer (I think -> verify!)
 https://github.com/hugelton/Felucca-WebApp    Web based emulator (verify!)

fm1-base
https://github.com/charlesvestal/fm1-base
-A base for M-VAVE FM-1 firmware, on felucca-bsp: the platform layer above the hardware 

SLOOP
https://github.com/isod89/sloop-fm1
-4-track groovebox with 3 synths and a drum machine. 
-12 synthesis engines, 153 sounds, 37 drum kits, your own samples

Clipper
https://github.com/isod89/clipper-fm1
-Dynthesizer with 23 engines and 407 sounds, one instrument (two in MULTI) like the original FM-1.
-No tracks, no drum machine, no song mode and no built-in samples. 
-Keeps SLOOP's 12 sound engines, effects, arpeggiator, step sequencer, USB audio and MIDI, and adds 
 HYBRID: one voice built from three oscillators (featuring supersaw), two filters and a modulation 
 matrix, with the whole patch editable in the browser.

Dinghy
https://github.com/zvenson/dinghy
-The smallest firmware for the M-VAVE FM-1 to build your own on.

https://github.com/Quixotic7/MvaveFM1Unbricker
-A recovery tool for the hardware unit to set it back into its original factory state if something 
 has gone terribly wrong with uploading the custom firmware which "bricked" the device. (verify!)
